guidenco setup

Configure the bridge over Bluetooth — no network needed.

This browser can't do Web Bluetooth. It only exists in Chrome and Edge, on desktop and Android. Safari and Firefox have never shipped it, and no browser on iOS has it. Open this page in Chrome.

Install

Flash Raspberry Pi OS, enable SSH and sign in, then run this once:

curl -fsSL https://raw.githubusercontent.com/onvo-ai/guidenco/main/install.sh | sudo bash

It works out which capture device you have, sets the boot overlays, and starts the service. Reboot when it finishes — the USB gadget that types and moves the mouse only appears at boot. After that the Pi advertises itself over Bluetooth and you can set it up below, no network needed.

Connection

offline

Pick the device named guidenco. The Pi must be powered on and within a few metres.
